# console-details-core

The `ConsoleDetails` facade (`put`, `remove`, `clear`, `flow`) and the `ConsoleKey` helper, without any UI. Depend on
it from modules that only write details.

```kotlin
implementation("io.github.thernal:console-details-core:<version>")
```

Usage, the UI and the release setup are described in [`details-ui`](../details-ui/README.md).
